# Kontribusi

Terima kasih telah membantu meningkatkan contoh platform OXY7O.

1. Buka issue dengan dampak dan hasil yang diharapkan.
2. Buat branch pendek dari `main` dengan satu tujuan kohesif.
3. Tambahkan atau perbarui test untuk perubahan perilaku.
4. Jalankan seluruh validasi repository secara lokal.
5. Buka pull request tanpa secret, credential, atau data internal.

Perubahan workflow, permission, dependency, dan security boundary memerlukan review maintainer. Kontribusi dilisensikan berdasarkan Apache License 2.0.
