# Kebijakan Keamanan

Jangan melaporkan kerentanan melalui issue, discussion, atau pull request publik. Gunakan fitur **Report a vulnerability** pada tab Security repository ini.

Sertakan versi, komponen terdampak, langkah reproduksi minimal, dampak, dan mitigasi yang diketahui. Jangan sertakan credential atau data produksi. Hanya release terbaru yang menerima perbaikan reguler; versi lama ditangani berdasarkan risiko.
